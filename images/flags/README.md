# Flags

One PNG per language code in `KnownPacks`, lower-cased: `es-es.png`, `it.png`, `pt-br.png`, `pl.png`.
Drawn at a fixed height, width following the image, so any aspect ratio is fine.

National flags are not copyrightable designs. These renderings come from Wikimedia Commons, public
domain, via `Special:FilePath/<file>.svg?width=48`:

| File | Source |
|---|---|
| `es-es.png` | `Flag_of_Spain.svg` |
| `it.png` | `Flag_of_Italy.svg` |
| `pt-br.png` | `Flag_of_Brazil.svg` |
| `pl.png` | `Flag_of_Poland.svg` |

Adding a language: drop `<code>.png` here. The csproj embeds the whole folder.
